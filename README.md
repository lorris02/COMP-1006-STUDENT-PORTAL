# Student Portal

Student Portal is a web application for managing student information and grades. Users can create and update records, find students quickly, and view a summary of their progress.

## Features

- Add, view, edit, and delete student records
- Search students by name or student ID
- Sort records by name, ID, or grade
- View total students, average grade, and passing students
- Validate entries and prevent duplicate student IDs
- Use a responsive layout on desktop and mobile

## Tech Stack

- **Frontend:** HTML and CSS
- **Backend:** PHP
- **Database:** MySQL with PDO
- **Testing:** PHP and Python

## Quick Start

With PHP 8.3 or newer installed, run this command from the project folder:

```bash
php -S localhost:8080 -t Php_files/Assignment_1
```

Open [Student Portal](http://localhost:8080/view.php) in your browser.

The app starts with fictional sample records. Demo changes are stored in your browser session, and you can restore the sample records at any time.
